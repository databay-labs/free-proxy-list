HProxy-48hHistory also consumes [HProxy's full recent-history export](https://github.com/hproxy-com/free-proxy-list/blob/main/all.txt). Its upstream 48-hour history is discovery input; every entry must pass this service's current validation before publication. This is additional coverage of HProxy, not an independent upstream.

Proxio-Combined consumes [Proxio's combined export](https://github.com/proxio-io/proxy-list/blob/main/all.txt) alongside its protocol subsets. The existing [Proxio](https://proxio.io/) CC BY 4.0 attribution covers this additional input as well.

Country enrichment for independently verified HTTP relay responses uses GeoLite2 data created by MaxMind, available from [MaxMind](https://www.maxmind.com/). The database is deployed privately and is not included in these public lists.
